Źródło przygotowane — publikacja aplikacji jeszcze nieaktywna

AltStore PAL wymaga paczki ADP przygotowanej po notaryzacji Apple. Aktualny plik IPA z GitHub Actions jest niepodpisany i nie może zostać opublikowany jako instalowalna wersja PAL.

Adres źródła AltStore PAL

https://novydev.pl/aplikacje/LibrusSync/altstore
Kod źródłowy na GitHubie

Co trzeba zrobić, aby aplikacja była instalowalna w PAL?

  1. Aktywować płatne członkostwo Apple Developer i przygotować aplikację w App Store Connect.
  2. Zgłosić LibrusSync do notaryzacji Apple zgodnie z procedurą AltStore PAL.
  3. Pobrać paczkę ADP i umieścić ją na serwerze bez modyfikowania jej plików.
  4. Uzupełnić źródło o identyfikator aplikacji, wersję, uprawnienia oraz adres manifestu ADP.
